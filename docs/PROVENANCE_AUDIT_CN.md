# 溯源审计（Provenance Audit）

**最后更新**：2026 年 7 月
**状态**：✅ 完成 —— 判定当前 MIT 发布产物不含 AGPL 受保护实现

---

## 摘要

本文档记录了对 docxgo 的 Git 历史（含上游 `fumiama/go-docx` 的 AGPL 时期快照）进行的法律与溯源审查，并得出结论。

**判定**：当前的 v2.11.0 MIT 发布产物是作者独立重写的成果，不包含任何具有可保护性的 AGPL 实现。历史快照保留其原始许可证；仅 v2 重写部分以 MIT 分发。

---

## 背景

- 上游项目 `fumiama/go-docx` 在一段时期内以 **AGPL** 发布。
- 本项目的 v2 是对该上游的**大幅重写**，目标是清晰架构、类型安全与现代 Go 实践。
- 重写后的 MIT 发布其许可证判定需要一份审计，以证明它不再包含 AGPL 受保护的代码。

---

## 范围与方法

审查覆盖：

1. Git 历史中的 AGPL 时期快照（提交、文件、行级差异）。
2. v2 重写引入的新代码（架构、接口、实现）。
3. 在重写部分与 AGPL 快照之间做代码相似度对比。
4. 许可证头、归属与署名声明（`CREDITS.md`）。

---

## 关键发现

### 1. 架构是全新的

v2 采用了与上游完全不同的清晰分层架构：

- `domain/`（接口） → `internal/`（实现） → `pkg/`（公共辅助）
- 接口驱动设计，依赖注入，功能选项模式
- 与上游的"上帝对象"结构无对应关系

### 2. 实现是独立编写的

- 序列化、读取、管理器等核心逻辑均从头编写
- 没有从 AGPL 快照复制函数、算法或结构
- 代码风格、错误处理、测试策略均为新设计

### 3. 相似度在合理范围内

- 任何表面相似（如 OOXML 元素名）源于 **ECMA-376 标准**，而非上游实现
- 方法签名相似源于 Go 惯用法与公开 API 约定
- 无逐行复制或大段搬运

### 4. 归因已记录

- `CREDITS.md` 完整记录了项目历史
- 上游贡献者（fumiama、gonfva 等）均被署名
- 重写部分的作者归属清晰

---

## 法律判定

| 项目 | 判定 |
|------|------|
| 历史 AGPL 快照 | 保留其原始 AGPL 许可证 |
| v2 重写产物 | MIT（不含可保护性的 AGPL 实现） |
| 重写与 AGPL 的代码重叠 | 无实质重叠 |
| 风险等级 | 低（可发布 MIT） |

**说明**：本判定基于代码审视，不构成正式法律意见。如有疑虑，建议咨询执业律师。

---

## 受影响文件

- `docs/IMPLEMENTATION_STATUS.md` —— 发布历史与许可证对齐

---

## 结论

当前 MIT 发布产物是作者独立重写的结果，不包含任何具有可保护性的 AGPL 实现。历史快照保留其原始许可证。项目可以 MIT 许可证安全分发。
