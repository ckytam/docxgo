## 已知限制与变通方案

### 1. 样式取回

**文件**：`internal/core/paragraph.go`
**限制**：`paragraph.Style()` 返回 nil（无法取回已应用的样式）。

**变通方案**：在调用 `SetStyle()` 时用你自己的代码跟踪已应用的样式名。

---

### 2. 域计算

**限制**：域以脏标记生成（Word 在打开时重新计算）。

**变通方案**：这是标准行为 —— Word 会在打开文档时更新域。要手动更新，在 Word 中按 Ctrl+A，再按 F9。

**说明**：这不是 bug —— 这就是 Microsoft Word 的工作方式。

---

### 3. 已弃用的 API 模式

**函数**：`Paragraph.AddField()`
**消息**："请改用 AddRun() 和 run.AddField()"

**说明**：这不是限制 —— 只是一个已弃用的 API 模式。通过 `run.AddField(field)` 域工作完全正常。全部 9 种域类型均已完整实现且可用。
